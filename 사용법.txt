Aside 설정 화면 한글패치 (Windows)

[사용법]
1_한글로_바꾸기.cmd    더블클릭하면 설정 화면이 한글로 바뀝니다.
2_영어로_되돌리기.cmd  영어 원본으로 복원합니다. (원본과 같은지 검사 포함)
3_상태_보기.cmd        한글/영어 상태, 패치 버전, 새 버전 여부를 보여 줍니다.

- 적용 후 Aside 설정 화면에서 F5(새로고침)
- 파란색 "Windows의 PC 보호" 창 → [추가 정보] → [실행]
- "디바이스를 변경하도록 허용" 창 → [예]
  (Aside 1.0.1022부터 설정 파일이 Program Files 안에 있어 관리자 권한이 필요합니다)
- Aside가 업데이트돼도 10분 안에 자동으로 다시 한글로 바꿉니다.
  (작업 스케줄러에 'AsideKoreanPatch' 작업 등록, 2번 실행 시 삭제)
- 패치 새 버전이 나오면 하루 안에 Windows 알림이 뜹니다. 받은 뒤 1번을 다시 실행하면 됩니다.
- 별도 설치는 필요 없습니다. Windows 기본 PowerShell로 동작합니다.

[참고]
- Aside 공식 기능이 아닌 개인 제작 패치입니다. 사용 여부는 본인 판단에 맡깁니다.
- 설정 화면만 바꿉니다. 대화창·에이전트·브라우저 본체는 건드리지 않습니다.
- 영어 원본 보관 위치: %LOCALAPPDATA%\AsideKoreanPatch\backup
- 숫자·날짜가 섞인 문장 등 일부는 영어로 남을 수 있습니다.
- 배포 페이지: https://github.com/echidna08/aside-korean
